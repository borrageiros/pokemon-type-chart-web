# ⚔️ Pokémon Type Chart

The classic damage chart for all 18 Pokémon types.

🌐 **[Open the chart](https://borrageiros.github.io/pokemon-type-chart-web/)**

## ✨ What it does

- 📊 Shows the full attack and defense table
- 🎯 Select up to two types for your Pokémon or the rival
- 🛡️ **My Pokémon** tells you what it is weak to and what it is strong against
- 💥 **Rival** tells you what beats it and what struggles against it

## 🛠️ Develop

```sh
yarn
yarn dev
```

## 📦 Build

```sh
yarn build
yarn preview
```

## 🚀 Deploy

A push to `main` builds the static site and publishes it on the `gh-pages` branch.

Live site: https://borrageiros.github.io/pokemon-type-chart-web/
